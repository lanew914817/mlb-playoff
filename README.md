# MLB 2026 季後賽海報

本地網頁，畫 2026 年 MLB 季後賽對戰樹。可以自己填預測勝場，也可以對照 MLB 官網的實際比分，並把海報存成圖片。開賽時間一律顯示台灣時間。

不需要安裝套件。Python 3.9 以上即可（用到標準函式庫的 `zoneinfo`）。

## 啟動

```bash
python3 server.py
```

然後打開 http://127.0.0.1:8765 。預設只有這台電腦連得到。

要讓同一個網路的人也能開：

```bash
HOST=0.0.0.0 python3 server.py
```

終端機會多印一行 `http://<區網 IP>:8765` 給他們。只有從這台電腦、而且沒有經過 tunnel 轉發標頭連進來的請求可以寫入；區網訪客和 Cloudflare Tunnel 進來的人，預測只存在他們自己的瀏覽器，「實際」是唯讀。

## 怎麼用

頁面上方有兩個分頁。

**預測。** 在海報上點隊徽，那一隊在該系列 +1 勝；右鍵或長按 −1 勝。贏到晉級門檻就自動往下一輪，前面一輪改了，後面的勝場會清掉。

**猜中。** 只要「實際」有系列賽打完，預測海報上晉級的隊徽右下角會標 ✓（猜中）或 ✗（沒猜中），底部顯示 CORRECT PICKS 幾 / 幾，戰績區也會列出。不想出現在圖上，取消海報下方的「海報標示猜中」。

**實際。** 比分來自 [MLB Stats API](https://statsapi.mlb.com)。本機按「從 MLB 更新」會把官網賽程和比分寫進 `data/`。一樣可以手動改勝場，再按「改回官網」還原。

海報下方可以下載圖片，檔名像 `mlb-2026-預測-20260929-1430.png`。「下載限動 9:16」會另外排一張 1080×1920 的直式圖給 IG／臉書限時動態：美聯在上、國聯在下，往中間的世界大賽晉級，上下留白避開限動的頭像列和回覆框。再下面是各系列戰績，以及依台灣時間排的賽程（標「若需要」的是系列還沒打完才會開的場次）。

## 晉級

| 輪次 | 系列 | 晉級 |
| --- | --- | --- |
| 外卡 | 3 戰 | 先拿 2 勝 |
| 分區賽 | 5 戰 | 先拿 3 勝 |
| 聯盟冠軍賽、世界大賽 | 7 戰 | 先拿 4 勝 |

對戰樹和 12 支球隊寫在 `bracket.py`；勝場與晉級規則只寫在 `static/rules.js` 一個地方。後段系列的對手前一輪還沒產生時，海報上先留空，也不能點。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `server.py` | 網頁和 `/api/state`、`/api/sync` |
| `bracket.py` | 球隊、對戰樹、MLB 賽程解析、台灣時間 |
| `static/rules.js` | 勝場與晉級規則（唯一一份） |
| `static/story.js` | 限動 9:16 直式圖的排版 |
| `static/` | 頁面、樣式、海報背景 |
| `data/schedule.json` | 賽程（含開賽 UTC） |
| `data/prediction.json` | 你的預測勝場（不進 git，第一次啟動自動建立） |
| `data/actual.json` | 實際比分（不進 git）；手動改過的系列在同步時會保留 |
| `logos/` | 啟動時從 MLB 抓的隊徽，已有的不會重抓 |
| `check_rules.js` | 晉級規則的檢查（需要 Node） |
| `check_advance.py` | 台灣時間與同步保留手改比分的檢查 |

```bash
node check_rules.js
python3 check_advance.py
```

兩個都印出 `ok` 就代表：外卡 2 勝、分區賽 3 勝、冠軍賽與世界大賽 4 勝會晉級，勝場加減不會超出規則，前面輪次改了後面會清空，猜中的計算，以及 UTC 轉台灣時間都還算對。
