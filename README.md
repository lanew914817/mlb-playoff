# MLB 2026 季後賽海報

本地網頁，畫 2026 年 MLB 季後賽對戰樹。可以自己填預測勝場，也可以對照 MLB 官網的實際比分，並把海報存成圖片。開賽時間一律顯示台灣時間。

不需要安裝套件。Python 3.9 以上即可（用到標準函式庫的 `zoneinfo`）。

## 啟動

```bash
python3 server.py
```

- 本機（可編輯）：http://127.0.0.1:8765
- 同一個網路的其他人：終端機會印出 `http://<區網 IP>:8765`，他們只能看

只有從這台電腦、而且沒有經過 tunnel 轉發標頭連進來的請求可以寫入。區網訪客和 Cloudflare Tunnel 進來的人都是唯讀。預測模式的點選會存在你自己的瀏覽器裡。

## 怎麼用

頁面上方有兩個分頁。

**預測。** 在海報上點隊徽，那一隊在該系列 +1 勝；右鍵或長按 −1 勝。贏到晉級門檻就自動往下一輪，前面一輪改了，後面的勝場會清掉。

**實際。** 比分來自 [MLB Stats API](https://statsapi.mlb.com)。本機按「從 MLB 更新」會把官網賽程和比分寫進 `data/`。一樣可以手動改勝場，再按「改回官網」還原。

海報下方可以下載圖片。再下面是各系列戰績，以及依台灣時間排的賽程（標「若需要」的是系列還沒打完才會開的場次）。

## 晉級

| 輪次 | 系列 | 晉級 |
| --- | --- | --- |
| 外卡 | 3 戰 | 先拿 2 勝 |
| 分區賽 | 5 戰 | 先拿 3 勝 |
| 聯盟冠軍賽、世界大賽 | 7 戰 | 先拿 4 勝 |

對戰樹和 12 支球隊寫在 `bracket.py`。後段系列的對手前一輪還沒產生時，海報上先留空。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `server.py` | 網頁和 `/api/state`、`/api/sync` |
| `bracket.py` | 球隊、對戰樹、勝場與晉級 |
| `static/` | 頁面、樣式、海報圖 |
| `data/schedule.json` | 賽程（含開賽 UTC） |
| `data/prediction.json` | 預測勝場 |
| `data/actual.json` | 實際比分；手動改過的系列在同步時會保留 |
| `logos/` | 啟動時從 MLB 抓的隊徽，已有的不會重抓 |
| `check_advance.py` | 晉級規則的小檢查 |

```bash
python3 check_advance.py
```

印出 `ok` 就代表外卡 2 勝、分區賽 3 勝、冠軍賽與世界大賽 4 勝，以及一筆 UTC 轉台灣時間，都還算對。
